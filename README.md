# Calculadora Minimalista (UI/UX & Front-End)

Projeto desenvolvido para a disciplina de **Design Profissional**, com foco em interface limpa (Dark Mode), hierarquia visual e boa experiência de uso.

## Funcionalidades
- Operações matemáticas básicas (adição, subtração, multiplicação, divisão e porcentagem).
- Histórico da última expressão calculada exibido acima do resultado principal.
- Interface responsiva com feedback visual nos botões.

## Tecnologias Utilizadas
- **HTML5** (estrutura semântica)
- **CSS3** (CSS Grid, variáveis de cor e transições suaves)
- **JavaScript** (manipulação do DOM e lógica de cálculo)

## Como visualizar
1. Baixe o arquivo `index.html` ou clone este repositório.
2. Abra o arquivo `index.html` em qualquer navegador web.
